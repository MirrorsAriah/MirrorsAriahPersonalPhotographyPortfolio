## 修复 index.astro 脚本块 TS 类型错误（编辑器红波浪线）
- 原因：Astro `<script>` 按 TS 模块校验。`getElementById` 返回 `HTMLElement|null`，`.src/.alt` 只在 `HTMLImageElement` 上；`querySelectorAll('.pf-card')` 返回 `Element[]`，`.dataset` 只在 `HTMLElement` 上；`open(i)`/`nav(d)` 隐式 any 参数。
- 修复：`querySelectorAll<HTMLElement>('.pf-card')`、`getElementById('pf-lb-img') as HTMLImageElement|null`、`querySelector<HTMLImageElement>('img')`，对所有 `lb*` 元素加 `if(...)` null 守卫，`open(i:number)`/`nav(d:number)` 显式标注，移除未用的 `e` 参数。
- 补丁：`lb` 仍报错——TS 不把 `if(cards.length && lb)` 的窄化带进嵌套函数闭包，`open/close/keydown` 内 `lb` 仍为 `HTMLElement|null`。改用 `const box: HTMLElement = lb`（声明类型即非 null）在闭包内替代 `lb`，消除"可能为 null"。
